
# RD184 Scientific Calculator

A native Android scientific calculator application
developed using Kotlin and Android SDK.

## Features

- Basic arithmetic operations
- Scientific calculations
- Degree and Radian modes
- Binary, Octal, Decimal and Hexadecimal calculations
- Complex number calculations
- Matrix operations
- Equation solving
- Statistical calculations
- Function tables
- Vector operations
- Fraction calculations
- Local calculation history
- Offline functionality

## Technology Stack

- Kotlin
- Android SDK
- Gradle
- SQLite
- Native Android UI

## Application

**App Name:** RD184 Scientific Calculator

**Package:** com.rd184.calculator
